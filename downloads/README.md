# Install Mosslight for testing

[Download the APK](https://github.com/wwds058-spec/puzzle/raw/refs/heads/apk-download/downloads/mosslight-review.apk)

Requires Android 8.0 or newer. Open the APK on your Android phone and allow installation from your browser or file manager if prompted.

This is the tested 1.0.0 review build, signed with a development key. It supports offline Classic play, daily challenges, and local saved progress. It has no ads or accounts. It is not a Play Store production release.

If you have another build signed with a different key, Android may reject the update. Uninstalling it first erases its saved progress.

A SHA-256 checksum is included in `SHA256SUMS.txt`.
